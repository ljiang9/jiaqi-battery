# 假期电量模拟器 jiaqi-battery

> 梗来源声明：致敬 2026-10-06 真实热梗「假期余额不足」——国庆长假进入最后两天，
> 大家的假期电量集体见底。本项目为善意玩梗的原创小游戏，与任何真实人物、企业无关，
> 文案均为虚构。

## 玩法

你开局拥有 **100 格假期电量**，7 天长假每天安排 **2 个活动**。

### 活动库

| 活动 | 电量 | 快乐 | 备注 |
|---|---|---|---|
| 景区打卡 | -18 | +12±4 | 人山人海，但朋友圈赢了 |
| 躺平刷手机 | -6 | +8±3 | 床是假期最后的堡垒 |
| 高速堵车 | -30 | -8±3 | 在高速上看免费日出 |
| 走亲戚 | -12 | -4~+14 随机 | 催婚现场 or 红包拿到手软 |
| 加班回消息 | -20 | -10±3 | 假期余额 -20，老板余额 +1 |
| 深夜烧烤 | +10 | +10±3 | 唯一回血手段，且治愈一切 |

### 每日结算

- 电量 **< 20**：进入**低电量模式**——当日快乐减半，并触发「⚠️ 假期余额不足」警告
- 电量 **= 0**：假期提前**关机**，直接结束
- 每天 40% 概率触发随机事件：老板深夜@全体成员 / 景区限流排队 3 小时 / 高速服务区充电排队

### 结局（按剩余电量 + 快乐总值）

| 结局 | 条件 |
|---|---|
| 假期提前关机 | 电量归零 |
| 假期刺客 | 快乐 ≥120 且电量 <20 |
| 满血复活打工人 | 电量 ≥60 且快乐 ≥60 |
| 电量耗尽的空壳 | 电量 ≤10 |
| 快乐透支户 | 快乐 ≥80 |
| 平平无奇假期 | 以上皆非 |

## 运行

```bash
python3 -m jiaqi_battery                        # 交互模式（需要终端）
python3 -m jiaqi_battery --auto --games 10 --seed 42
python3 -m jiaqi_battery --auto --games 3 --seed 7 --verbose   # 每日战报
```

`--auto` 下 AI 按贪心策略选活动：在不关机的前提下最大化「快乐期望 + 电量变化×0.6」。
